Decisions I made against the brief

Each one is defensible on its own; each leaves your existing code tokens in place.

Three tokens fail AA in the pairings the brief implies

Accent #00A99D with white is 2.93:1; Danger #D64545 as text is 4.38:1; Border #E3E8EF as a control boundary is 1.29:1. Rather than change tokens already in code, I added three companions used only for those roles: #007A72, #C13333, #8C97A8. Full measured table in document 01.

Radius sm 6px is the working default, not 10px

10px on a 32px dense control reads soft and clips the corner of tabular data. Cards and panels keep 10px; drawers and modals keep 14px.

Status pills are tinted fill with a deep label, never saturated fill with white text

Four of the seven room hues fail AA with white at 12px. Every pill and tile also carries a dot or icon, so the folio still reads in greyscale.

The room status board is not on the mobile dashboard

248 tiles at 390px is unreadable, and the movements list answers the same question. Housekeeping mobile carries room state instead, where it belongs.

Mandatory states are drawn in full on the hero screens and documented as patterns elsewhere

The five states for all 24 screens is 120 artboards of mostly repeated pattern. The dashboard and the table component carry all five fully; every other screen inherits those patterns, which is what a build team actually needs. Say the word if you want them enumerated screen by screen for a specific review.

Open with you

  1. Tax and locale figures. I used BDT with VAT 15%, service charge 10% and a 1% tourism levy, and a BIN in the format 004212938-0201. If your real rates or BIN format differ, the folio and every settlement panel change with them.
  2. Odoo model mapping. Treating reservations, folios and the guest record as Odoo models rather than a parallel data layer. Worth one session with your dev lead before build to name the fields.
  3. Figma rebuild. No Figma connector is available here, so this is the spec plus working mockups. Every measurement, token and state is stated so the file can be built lossless — and the page numbering matches the file structure you specified.
