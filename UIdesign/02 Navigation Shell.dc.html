Navigation shell

Three coordinated zones: the global app drawer, the contextual module sidebar, and the 56px top bar. Every screen in pages 04–07 sits inside this frame, so it is drawn once here and referenced by name afterwards.

Reasoning · hierarchy
  • Two levels of navigation is the hard part. The drawer answers “which app” and is transient; the sidebar answers “where in PMS” and is permanent. Mixing them is how Odoo back-offices usually go wrong — the app list ends up competing with the module list for the same 240px.
  • The property switcher sits in the top bar, not the sidebar, because it scopes everything including the sidebar badge counts. It is the only top-bar element allowed a surrounding box, so it never reads as a page title.
  • Quick actions are three fixed buttons, never a “+ New” menu. A front desk agent should reach Check In in one click; a dropdown costs two and a decision.
